# Use Architecture Decision Records

## Context and Problem Statement

The project needs a short, durable record of important technical and release
decisions so future changes do not depend only on chat history.

## Decision Outcome

Use brief numbered ADRs in `docs/decisions/`. Accepted decisions are not
rewritten; a later ADR supersedes an earlier one when needed.
